Connected sources

The brain reads the sources you connect. That pack is named on the quote, and it is finite. Connecting means we read the named sources you approve, inside your account, not ours. We do not see sources you do not connect. Slack, Microsoft 365, a CRM, or on-prem files in month one is a Standard conversation, said before you sign.

This node Connected sources bounded-by Only connected sources required-by What a receipt contains

Connecting a source means Mnemma may read it, under the container you declare at sign-in. It does not mean we can see the rest of the company.

The starter pack is Gmail, Google Drive, Google Calendar, and GitHub. Gmail and Drive size the history. Calendar and GitHub join the same map; they do not change the planning-band math at this precision.

Slack, Microsoft 365, a CRM, or on-prem file shares in month one is a Standard conversation — or a later change order — not a surprise inside the starter pack.
