Classification containers

Rules live on the data, not on each tool. Default-closed. Unclassified is refused. Every source signs a container before it is read. Tools that connect later inherit the same rules. We never hold your data in our cloud, so we cannot lose what we never have.

This node Classification containers

Today every AI purchase is its own security review — configured per tool, wrong per tool, forgotten per tool.

In Mnemma the class travels with the knowledge. Containers are RED or GREEN. Access is per identity. A tool that connects inherits the walls. Govern once.

RED serves only to principals whose model path is cleared for RED. A GREEN principal asking a RED question is denied — and that deny is a first-week test we run in front of you.
