The model-swap mechanism

The brain is the asset. The model behind it is a slot, not a bet. Year one, you can swap the model that reads and writes the graph without re-ingesting anything — the same brain, a different engine.

This node The model-swap mechanism depends-on Standard deployment — your environment

Ownership is the point of the whole system, and ownership means the model can never be the lock. The graph, its receipts, and its classification are yours and stay put. The model is the layer that reads and writes them — and that layer is replaceable.

Year one, you can swap the model behind the same brain with no re-ingest. Nothing about the asset moves; only the inference engine changes.

One honest boundary: swapping the chat client you talk to, or a copilot embedded inside a workflow, is a design cherry we may build — not a year-one promise this page makes. This page claims the model swap and nothing more.
